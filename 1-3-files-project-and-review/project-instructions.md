【案件背景】
社團法人甲子公益協會委託乙創科技有限公司開發資訊系統，雙方就報表匯出功能、驗收、追加需求、尾款、原始碼交付及智慧財產權等事項產生爭議。甲方向丙信法律事務所提出初步法律諮詢；正式委任關係仍待確認。

【開發契約當事人】
- 甲方：社團法人甲子公益協會，委託方。
- 乙方：乙創科技有限公司，系統開發方。

【法律顧問】
- 丙信法律事務所：甲方的外部法律顧問。
- 丙信不是開發契約當事人，也不是中立仲裁者；初次來信階段僅屬初步諮詢，尚未設定正式委任關係。

【案件文件】
- 客戶來信：代表甲方提出的陳述、疑問及委託需求，不等於所有內容都已經證實。
- 委外開發契約：雙方契約文字的主要依據，引用時必須標示條號。

【Project Knowledge 的資料分層與更新規則】
- `client-email.pdf` 與 `development-contract.pdf` 是原始文件；不得以摘要或工作筆記取代，也不得修改原始文件。
- `案件工作脈絡.md` 是經人工覆核後加入的案件工作摘要，不是原始證據，也不是正式法律意見。
- 對話中的分析不會自動保存到 Project Knowledge。只有經人工確認、修正來源與資料狀態後，才手動加入或更新 `案件工作脈絡.md`。
- 工作脈絡與原始 PDF 不一致時，以原始 PDF 為準，標示差異並重新查證；不得直接覆寫原始 PDF。

【工作規則】
1. 使用臺灣正體中文。
2. 分析時優先依據 Project 中提供的原始文件。
3. 明確標示每項資訊的來源，不得混淆客戶陳述與契約約定。
4. 引用契約內容時，必須標示條號；引用客戶來信時，標示來信段落或相關敘述。
5. 區分「文件明載的內容」、「當事人主張」、「文件未記載或不明確的事項」及「分析推論」。
6. 不得把推論寫成已經證實的事實。
7. 不得自行編造法條、判決或法律依據；若需要法律依據，應另外查證並標示來源。
8. 資料不足時，應列出需要補充的資料，不要自行猜測。
9. 提供的是案件資料整理與初步分析，正式法律意見仍須由律師覆核。
