輸出位置：output/delivery-analysis.xlsx

請建立以下三張工作表：

一、原始資料
- 保留來源工作簿的全部原始欄位與資料。
- 不得修改原始數值或刪除資料列。

二、分析明細
- 保留每個項目的原始資料。
- 新增「工時差異」欄位，計算實際工時減去預定工時。
- 新增「完成日期差異」欄位，計算實際完成日減去預定完成日。
- 若實際完成日為空白，完成日期差異也必須保持空白。
- 保留每個項目的驗收狀態及付款金額。
- 為方便下一個操作建立圖表，請將「項目名稱」、「預定工時」、「實際工時」三欄安排在分析明細最前面的連續欄位（A、B、C 欄），每個項目各列一筆。
- 其餘原始欄位及計算欄位接續排列，不得遺漏資料。

三、統計摘要
請計算：
- 預定工時總計。
- 實際工時總計。
- 工時差異總計。
- 表格中已記錄的付款金額合計。
- 各項目的工時差異及完成日期差異。

計算與格式要求：
- 優先使用 Excel 公式，不要只把計算結果寫成固定數字。
- 日期差異以天數呈現。
- 空白完成日不得當成 0 天。
- 金額以新臺幣顯示。
- 所有分析都要能追溯到原始資料列。
- 不要修改 input/delivery-records.xlsx。
- 不要建立任何圖表、圖表工作表或圖表預覽。
- 不要根據這份表格判斷任何一方是否違約。

完成後，請說明三張工作表的用途及使用的主要公式，並確認整份工作簿尚未插入圖表。
