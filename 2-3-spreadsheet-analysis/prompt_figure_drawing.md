這是一個 Computer Use 示範。請使用螢幕上可見的 Microsoft Excel 圖形介面，以滑鼠及鍵盤完成以下工作。

請勿改用 Python、程式碼、命令列或直接讀寫 XLSX 檔案的方式完成操作；本次教學重點是觀察你如何操作桌面 Excel。如果無法使用螢幕操作，請停止並說明原因，不要假裝已完成。

請依序操作：

1. 在桌面介面開啟 output/delivery-analysis.xlsx。
   - 如果找不到這個檔案，請先詢問我，不要猜測其他路徑。
   - 不要開啟或修改 input 中的原始 XLSX。

2. 切換到「分析明細」工作表。
   - 確認 A、B、C 欄的欄位標題依序為「項目名稱」、「預定工時」、「實際工時」。
   - 找出最後一筆項目資料所在列。
   - 使用 Excel 名稱方塊選取從 A1 到 C 欄最後一筆資料的完整範圍，包含標題列，但不要選取空白列或統計總計。

3. 使用 Excel 功能區的「插入」→「插入直條圖或橫條圖」→「2-D 群組直條圖」建立圖表。
   - 如果 Excel 沒有正確辨識資料範圍，請先確認選取範圍再插入。
   - 不要改動資料表中的任何數字、公式或欄位。
   - 將圖表放在「分析明細」工作表的資料表旁邊，不要覆蓋資料表。

4. 設定圖表。
   - 圖表標題：「各項目預定工時與實際工時比較」。
   - 水平座標軸代表「項目」。
   - 垂直座標軸代表「工時（小時）」。
   - 圖例應能區分「預定工時」與「實際工時」。
   - 確認每個項目都有呈現在圖表中，且兩組數列沒有顛倒。

5. 儲存 output/delivery-analysis.xlsx。

完成後，請回報：
- 實際選取的資料範圍。
- 是否透過 Excel 圖形介面成功插入 2-D 群組直條圖。
- 圖表標題、座標軸及圖例設定。
- 是否已儲存檔案。
- 若有任何項目無法確認，請明確說明。

請勿修改 input 中的原始 XLSX，也不要刪除或覆寫其他檔案。
