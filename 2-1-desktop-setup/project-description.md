這個 Project 是 Topic 2「Claude Desktop 辦公流程」的共同工作空間。請在 Topic 2.1、2.2、2.3 全程沿用同一個 Project，不要每個單元重新建立。

唯一工作範圍是透過 Add folder 加入的電腦本機 Claude-Office-Workflow-Practice 資料夾：
- input：課程提供的虛構 PDF、XLSX 原始素材。
- output：Claude 產生的 Word、Excel 與其他練習成果。

Topic 2 的實作工作包括：
1. 資料夾讀取測試：實際讀取 input 中的 PDF 與 XLSX，並在 output 建立 permission-check.docx。
2. 契約 PDF 分析：閱讀 input/development-contract.pdf，辨識需要注意或待確認的契約條款，建立 output/契約條款注意與修正清單.docx。
3. Excel 資料分析：讀取 input/delivery-records.xlsx，檢查資料品質，建立包含原始資料、分析明細及統計摘要的 output/delivery-analysis.xlsx。
4. Computer Use：使用這台電腦上安裝的 Microsoft Excel 桌面版，開啟 output/delivery-analysis.xlsx 建立工時比較圖，再依照學員以自然語言提出的要求修改圖表標題。

請遵守以下工作規則：
- 來源素材只從 Claude-Office-Workflow-Practice/input 讀取；所有新建成果都儲存到 Claude-Office-Workflow-Practice/output。
- 如需繼續編輯 output 中已產生的成果，只修改本次任務指定的成果檔案。
- 不得修改、覆寫、移動或刪除 input 中的原始檔案。
- 不得自行存取或修改 Claude-Office-Workflow-Practice 資料夾以外的電腦檔案。
- 不得使用真實案件資料或含有個人資料的檔案。
- 不得只根據檔名或副檔名猜測內容；分析必須以實際讀取的素材為依據。
- 契約分析僅為教學練習，不得將分析推論寫成已確認的法律結論；仍須由律師核對。
- Computer Use 的桌面操作使用本機 Microsoft Excel，不要改用 Excel 網頁版。
